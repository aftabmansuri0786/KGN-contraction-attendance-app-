# KGN Construction Attendance App

A complete, production-ready Android mobile application built for **KGN Construction** (India). Designed for the single owner/administrator to manage workers, multiple construction sites, daily attendance, wages, overtime, advances, payments, and financial reports directly from an Android phone.

---

## 🏗 Key Features

1. **Owner-Only Authentication**:
   - 4-digit master security PIN (Default: `1234`, configurable anytime in Settings).
   - Session lock and instant owner lock.
   - Zero access for workers/supervisors; no unauthorized public registration.

2. **Bilingual Hindi + English Interface**:
   - One-tap language toggle on top bar (`English` ⇄ `हिंदी`).
   - Every label, button, and report translated for seamless construction site use.

3. **Construction-Themed Design**:
   - Safety Orange (`#FF6D00`), Charcoal Black (`#1E2022`), and crisp off-white surfaces.
   - Dark theme support.
   - High-contrast touch targets for direct outdoor site operation.

4. **Multiple Construction Sites**:
   - Add and track multiple construction projects (e.g., Metro City Heights, Green Valley Villa).
   - Site-wise worker allocation and site-wise labour cost tracking.

5. **Daily Attendance & Overtime**:
   - Calendar date switcher with previous/next buttons.
   - **"Mark All Present" (सब उपस्थित)** one-tap action.
   - Attendance statuses: Present (1.0), Half-Day (0.5), Absent (0.0), Paid Leave (1.0).
   - Overtime stepper (-/+ 0.5h, 1h, 2h).
   - Wage rate snapshotting preserves historical financial integrity.

6. **Wages, Advances & Payment Vouchers**:
   - Track worker advances (Cash, UPI, Bank Transfer).
   - Record wage payments and settlements.
   - Generate printable/shareable **Payment Vouchers** with direct WhatsApp sharing.

7. **Reports & Exports**:
   - Daily & Monthly Attendance Registers.
   - Worker Ledger and Site-wise expense reports.
   - Direct CSV export and WhatsApp summary report sharing.

## 📱 Mobile-Only APK Installation Steps

1. **Download APK**:
   - In Google AI Studio, navigate to the top-right settings menu and click **Export APK** or trigger the GitHub Actions workflow to download the `app-debug.apk`.
2. **Install on Phone**:
   - Open your Android phone's Downloads folder.
   - Tap `app-debug.apk`.
   - If prompted by Android, tap **Settings** and enable **"Allow from this source"** for your browser or file manager.
   - Tap **Install**.
3. **Launch & Unlock**:
   - Open **KGN Construction**.
   - Enter default PIN: `1234`.
   - Change your PIN in **Settings** if desired.

## ☁️ Firebase Firestore Setup

1. Create a Firebase project at [https://console.firebase.google.com](https://console.firebase.google.com).
2. Add an Android app with package name `com.aistudio.kgnconstruction.vytqwa`.
3. Download `google-services.json` and place it in the `app/` directory.
4. Deploy security rules from `firestore.rules`.

## 💰 Google AdMob & app-ads.txt Setup

### 1. AdMob App Configuration
- **Application ID in `AndroidManifest.xml`**:
  Configured with Google's official test ID for development: `ca-app-pub-3940256099942544~3347511713`.
  When publishing to production, update this value in `app/src/main/AndroidManifest.xml` with your live AdMob App ID.
- **Banner Ad Unit ID in `AdMobConfig.kt`**:
  - Test Banner ID: `ca-app-pub-3940256099942544/6300978111`
  - In `app/src/main/java/com/example/util/AdMobManager.kt`, set `LIVE_BANNER_AD_UNIT_ID = "[YOUR LIVE BANNER ID]"` when ready to release.

### 2. Publishing `app-ads.txt` (Mobile-Friendly via GitHub Pages)
The authorization line generated by AdMob is:
```text
google.com, pub-7775135423003106, DIRECT, f08c47fec0942fa0
```
This exact line is saved in `/app-ads.txt`.

**Steps to publish from your phone without a PC**:
1. Open your repository on **GitHub** in your phone's browser.
2. Ensure `app-ads.txt` is in the root directory of your repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Build and deployment**, select `Deploy from a branch` and choose `main` branch `/ (root)`.
5. GitHub will generate your free site URL: `https://<your-username>.github.io/<repo-name>/`.
6. Add this domain as your **Developer Website** in Google Play Console store listing.
7. Google AdMob crawler will crawl `https://<your-domain>/app-ads.txt` within 24–48 hours and mark your app as **Authorized**.
